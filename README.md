# Landfolio

200 landing page templates carefully brewed by **local AI only - no cloud, no api**.
Files are standalone, zero build step. Code is meh, I only cared about agent harnessing and visual diversity.

**👀 Live Demo:** [ctlsim.github.io/landfolio](https://ctlsim.github.io/landfolio/)

## 🎨 Why this exists

Most landing page templates are hand-crafted, expensive, or locked behind paywalls.
Landfolio proves local AI can generate beautiful, visually distinct templates across every aesthetic - from brutalist to kawaii to steampunk - in minutes, not days.

> And mostly to explore the wonderful world of harnessing local AI with a limited context window 🫠

## 🚀 Quick Start

1. **Pick** - Find a style that inspires you.
2. **Browse** - Open any `.html` page directly in your browser
3. **Save** — Copy the `.html` file, clone the repo (`git clone ...`), or right-click → Save Page As. Zero 
dependencies, no install.
4. **Serve** — `python3 -m http.server 3210`

> These templates are starting points, not final products. Use them as inspiration and build from there.
